# 我的持股明細與分析

有兩種用法：

- **手機也能新增（建議）**：持股存在你的 Supabase，網站登入後可新增、修改，每天自動計算。設定步驟見 [supabase/README.md](../supabase/README.md)。
- **只在自己電腦用**：下面的 CSV 方式。

CSV 方式的持股**只在你自己的電腦上跑**：輸入放在 `private/`，輸出放在 `site/data/private/`，兩個都在 `.gitignore` 裡，不會被推上 GitHub，也不會出現在公開的 GitHub Pages 網站。

## 使用方式

```bash
mkdir private
copy holdings\examples\holdings.example.csv private\holdings.csv   # Mac/Linux 用 cp
# 用 Excel 打開 private/holdings.csv 改成你的持股，存檔時選「CSV UTF-8」
python -m holdings            # 抓行情、算數字、請 Claude 寫健檢（需要 ANTHROPIC_API_KEY）
python -m holdings --no-ai    # 只算數字，不呼叫 Claude
cd site && python -m http.server 8000   # 打開 http://localhost:8000 → 我的資產
```

沒有網路或 API key 時，`python tools/make_sample_holdings.py` 會用範例持股和假行情產生預覽。

## private/holdings.csv 欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| 代號 | ✓ | 台股寫 `2330`（上櫃寫 `6488.TWO`），美股寫 `NVDA` |
| 股數 | ✓ | 可以有小數（美股零股） |
| 成本 | ✓ | 每股平均成本，原幣（台股台幣、美股美元），建議含手續費 |
| 買入日期 | | `2025-03-12`，用來算持有天數與年化報酬（持有未滿 90 天不算年化） |
| 名稱 | | 顯示用 |
| 帳戶 | | 例如 永豐、複委託；頁面上可分帳戶檢視。**不會送給 Claude** |
| 產業 | | 用來算產業配置，例如 半導體、ETF、金融 |
| 投資理由 | | Claude 每次會檢查這個理由是否還成立 |
| 買入匯率 | | 美股才需要，例如 `32.8`；沒填就用買入日的歷史匯率 |
| 市場、幣別 | | 通常不用填，程式從代號判斷 |

同一檔在不同帳戶可以分兩行；占比會合併計算。

## private/transactions.csv（選填）

只記「賣出」與「股息」，用來算已實現損益與今年股息。欄位：`日期,代號,類型,股數,價格,成本,金額,手續費,帳戶`。賣出填股數、賣價、那批的平均成本、手續費＋交易稅；股息只填金額（稅後實收）。範例在 `examples/transactions.example.csv`。

## 算了什麼（全部由程式計算）

- 每檔與總體：台幣市值、今日損益、未實現損益與報酬率、年化報酬；美股損益拆成「股價」與「匯率」兩部分
- 配置：依個股、產業、市場、幣別、帳戶的占比；單一持股超過 20%、單一產業超過 40% 標示（上限在 `holdings/config.py` 改）
- 集中度：最大一檔、前三檔占比、「相當於平均分散在幾檔」
- 與大盤比較：以目前持股回推過去一年的報酬、最大回撤、波動度、對台股大盤的 beta，對照加權指數與 S&P 500
- 情境試算：費半、加權指數、S&P 500 各跌 10%，以及美元貶 3% 時資產大約少多少（依各持股過去一年的 beta 估算）

## Claude 寫的健檢

一次呼叫，送出的只有：代號、名稱、產業、占比、報酬率、持有天數、投資理由，以及今天早報的財經重點。**不送帳戶、股數、金額**。Claude 回傳一句話總結、集中度說明、每檔投資理由是否仍成立、今天新聞碰到哪些持股（偏多／偏空）、接下來留意的事。不給買賣建議。AI 失敗時保留上一份的文字，數字照樣更新。
